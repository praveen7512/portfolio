# Praveen Sahu — Portfolio

Personal portfolio of **Praveen Sahu**, Android Engineer @ Swiggy Instamart.
Live: https://praveen7512.github.io/portfolio/

- Static HTML/CSS/JS, no build step.
- All content lives in `data.js`; `main.js` renders it and pulls live GitHub stats.
- Run locally: `python3 -m http.server` then open http://localhost:8000
- Deploy: GitHub Pages from `main` / root (`.nojekyll` included).
